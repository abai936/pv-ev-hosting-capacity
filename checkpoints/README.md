# Checkpoints

A short report after every big checkpoint. Read these to see what has been done and what is happening now. Later they become the project's progress log on GitHub.

Each report has: **Figures** (1 to 2 plots that show the result at a glance; made by `scripts/make_figures.py` from the results CSVs, never drawn by hand; saved in `checkpoints/img/`), **Done**, **Works (with real test output)**, **Failed or skipped**, **Decisions made**, **Next**.
Labels: checked / believed / guessed. Simulated numbers are never called measured.
