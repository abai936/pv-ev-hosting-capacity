# R2: Feeder files and licences (simulation-only hosting-capacity project)

All pages were read on 2026-11-18. "VERIFIED" means the fact appeared on the cited page via WebFetch (a summariser read it, I did not see raw HTML). "INFERRED" means it comes from secondary sources, search snippets or my own background knowledge and must be checked before relying on it. No zip file was downloaded or opened, so zip contents are unverified.

## Summary

- The official IEEE PES feeder page (cmte.ieee.org/pes-testfeeders/resources) hosts zips for 13, 34, 37, 123, 8500-node and the European LV feeder, but its page does not say what file formats the zips hold. Ready-to-run OpenDSS .dss versions of 13/34/123/8500 are in EPRI's OpenDSS SVN folder "IEEETestCases" on SourceForge.
- The European LV feeder (906 buses, 0.416 kV, 55 single-phase loads, 1-minute daily profiles) is on the IEEE page as European_LV_Test_Feeder_v2.zip. It is NOT in EPRI's IEEETestCases folder listing. Whether the zip contains .dss files is unconfirmed (I believe it does; check by downloading it yourself).
- Licences: OpenDSS = BSD-3-style (EPRI); DSS-Python and DSS C-API = BSD-3-Clause; OpenDSSDirect.py = BSD-style (NREL/Alliance for Sustainable Energy, 2017; PyPI mislabels it "Other/Proprietary"). None of the IEEE feeder pages state a licence for the feeder data, so the safe choice for an MIT/BSD repo is to link to the files and provide a download script, not commit them.
- Safest Windows route for Python only: `pip install dss-python` and/or `pip install opendssdirect.py` inside a venv (PyPI, dss-extensions project). Avoid third-party SourceForge/other mirrors; the EPRI installer comes from EPRI's own site or the "electricdss" SourceForge project.
- For an NZ-style 50 Hz, 230/400 V LV study, the European LV feeder (416 V, single-phase unbalanced loads, 1-minute profiles) is the best fit. The IEEE 13/34-bus feeders are 4.16 kV / 24.9 kV, 60 Hz North American MV feeders. NONE of them supplies a year-long load shape.
